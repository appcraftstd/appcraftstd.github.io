This website

Bu web sitesi

This website uses no cookies, no analytics and no third-party trackers, and loads no external fonts or scripts. Your language choice is remembered only in your own browser's local storage. The site is hosted on GitHub Pages; GitHub may log visitors' IP addresses for security purposes, as described in the GitHub Privacy Statement.

Bu web sitesi çerez, analiz aracı veya üçüncü taraf izleyici kullanmaz; harici yazı tipi ya da betik yüklemez. Dil tercihiniz yalnızca kendi tarayıcınızın yerel depolamasında hatırlanır. Site GitHub Pages üzerinde barındırılır; GitHub, güvenlik amacıyla ziyaretçilerin IP adreslerini GitHub Gizlilik Bildirimi'nde açıklandığı şekilde kaydedebilir.

When you email us

Bize e-posta gönderdiğinizde

If you write to us, we receive your email address and whatever you include, and use them only to reply. We delete support emails once the matter is resolved, unless the law requires us to keep them.

Bize yazarsanız e-posta adresinizi ve yazdıklarınızı alır, yalnızca yanıt vermek için kullanırız. Destek e-postalarını, yasal bir saklama zorunluluğu yoksa, konu çözüldükten sonra sileriz.

Contact & data requests

İletişim & veri talepleri

For any privacy question or a request about your data — including deleting a leaderboard nickname — write to us. Please name the game. We answer within 30 days.
